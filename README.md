# Visualizing Autonomic States Through VR Biofeedback to Support Mindfulness

This repository contains the analysis notebook used for the paper:

**Designing VR for Chronic Pain: Visualizing Autonomic States Through VR Biofeedback to Support Mindfulness**

The notebook evaluates a machine learning-based physiological inference pipeline for the *Virtual Meditative Walk* (VMW), a closed-loop virtual reality biofeedback environment designed to support mindfulness-based chronic pain management. The analysis uses Electrodermal Activity (EDA) and Heart Rate Variability (HRV) features to estimate stress-related physiological states and compare this approach with the original VMW skin conductance slope-based feedback rule.
